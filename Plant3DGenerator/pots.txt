# Plant3DGenerator pots library — Meshy-generated, scaled at runtime côté iOS.
# Format: pot_id | Display Name | style hint (English, Meshy-friendly) | top_diameter_cm | height_cm
#   - pot_id (col 1) : identifiant snake_case ; servira de nom de fichier
#     `output/pot_<id>.usdz` et de FK dans Plant.defaultPotId.
#   - Display Name (col 2) : nom français pour l'UI.
#   - style hint (col 3) : passé à `pipeline.build_pot_prompt(style=)`.
#   - top_diameter_cm (col 4) : diamètre d'ouverture en cm — sert à
#     `auto_size=True` côté Meshy + au scaling runtime côté iOS pour
#     matcher la motte d'une plante (cf bucket horticole : ~10 / 14 / 20 / 28 cm).
#   - height_cm (col 5) : hauteur du pot. Le ratio diameter/height détermine
#     la silhouette (tall narrow vs wide low).
# Convention : tous les pots sont vides (no plant, no soil clump), origin
# au pied du mesh. Côté iOS, le pot affiche un disque de terre brun à
# l'intérieur de sa rim ; la plante s'y inscrit à `Y = pot.rimY`.
