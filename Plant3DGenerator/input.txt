# Plant3DGenerator input — 30 decorative plants for the Arbore catalogue
# Format: Common Name | Latin Name | hint | height_m | habit
#   - column 3 (hint) describes ONLY le plant (foliage, color, habit).
#     Convention "ligne de terre" : le mesh n'inclut PAS de motte / root
#     ball / soil clump. La plante est coupée net à la base de la tige
#     (Y=0 du USDZ = surface de la terre). Les pots, eux, ont leur disque
#     de terre visible à leur rim — c'est eux qui portent la terre. Ne
#     jamais mentionner "pot", "soil", "root", "motte" dans le hint.
#   - column 4 (height_m) is the realistic indoor height in meters. Passée
#     dans le prompt avec Meshy `auto_size=True` pour que le USDZ revienne
#     déjà à l'échelle réelle ; sera aussi stockée backend-side en
#     Plant.heightMeters pour le framing de la thumbnail du catalogue.
#   - column 5 (habit, optional, default "upright") — pilote le bloc
#     prompt cascade-aware (cf issue #185). Valeurs supportées :
#       * upright   — port dressé, tout au-dessus de Y=0 (Sansevière, Olivier)
#       * trailing  — vines retombantes hors du pot, Y<0 (Pothos, Bougainvillier)
#       * arching   — frondes/tiges qui s'arquent vers l'extérieur (Fougère Boston, Gaura)
#       * bushy     — feuillage dense compact au-dessus (Monstera, Buis, Hortensia)
#     L'omission ou une valeur inconnue retombe sur "upright" (safe default).
#     Côté backend, sera stocké en Plant.habit pour driver le pot scaling
#     runtime côté iOS (issue #185 solution C).
# Lines starting with # are ignored.
#
# Usage principal — interface web :
#   1. `python server.py` (lance http://localhost:5555, ouvre Safari)
#   2. Clique sur une plante dans la liste → bouton "Preview only" pour un
#      test pas cher (20 crédits), ou "Generate" pour la full pipeline
#      (30 crédits, USDZ texturé inclus).
#   3. Le `<model-viewer>` Google affiche le GLB inline dès que la stage
#      preview termine — pas besoin de QuickLook.
# Backup avant régénération : si tu veux préserver le mesh existant,
# renomme-le dans `output/` (le pipeline écrase sinon).
#
# Usage CLI (optionnel — headless / scripts) :
#   python generate.py             # première ligne seulement
#   python generate.py --all       # toutes
#
